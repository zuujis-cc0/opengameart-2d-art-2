# The Zip Includes
- Large collection of 2D objects both as individual images and optimized atlases.
- Every object comes with in a greyscale and color version.
- The format is .PNG with transparency. 
- All sprites follow a standard of 1 meter = 32 pixels, so everything is compatible with one another. 
- The images are designed for direct game development use, being modular, standardized, swappable and consistent in style.
