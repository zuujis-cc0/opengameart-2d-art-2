This Quake's 256-color palette, as well as the colormap used by the game. I mirrored it to OpenGameArt because it is sometimes furiously difficult to find palettes of old classics and i want to preserve this one.

Note that the .ase file included is an Adobe Swatch Exchange version of the palette, not an Aseprite file.
For technical information, including usage of the palette in that game and a script that generates a near-identical colormap, see here: https://quakewiki.org/wiki/Quake_palette

This palette is below the threshold of originality and therefore in the public domain. The link above includes a citation of id software's John Carmack agreeing with and reinforcing this.

Palette and colormap by id software artists. Quake wiki mirror and technical information credits are included on the link above. File conversions by Spiney. OGA mirror by Croomfolk, unchanged except for bundling in the colormap file.
